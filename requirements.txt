# fgas-to-pk-ml --- Python dependencies (pip), cross-platform
#
# Designed to install matched VERSIONS on both:
#   - NERSC Perlmutter   (Linux x86_64, NVIDIA A100 -> CUDA torch)
#   - MacBook Pro M5     (macOS arm64, Apple Silicon -> Metal/MPS torch)
# Nearly everything below ships wheels for both platforms and installs without
# compiling. The ONE exception is Pylians (sdist-only) -- see its block.
# Verified + resolved consistently 2026-06-17.
#
# CROSS-PLATFORM RULES (important):
#   1. Do NOT replace this with `pip freeze`. A freeze on NERSC pins the
#      nvidia-*-cu13 / triton CUDA stack, which has no arm64-mac wheels and
#      will fail to install on the Mac (and vice versa: a Mac freeze gives you
#      a CPU torch on NERSC). Pin top-level packages only, as done here.
#   2. Keep torch as a clean upstream pin (`torch==2.12.0`) with NO `+cuXXX`
#      local tag and NO `--index-url`. PyPI then serves the CUDA wheel on Linux
#      and the MPS wheel on macOS automatically.
#   3. Pick the compute device at runtime, not at install time -- see SETUP
#      notes for the cuda/mps/cpu helper so the code itself stays identical.
#
# Target: Python 3.12 (3.11 also supported; numpy 2.4 requires >= 3.11).
# Install into an activated env:  pip install -r requirements.txt
